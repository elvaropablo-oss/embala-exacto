# EmbalaExacto

Calculadoras estáticas en español para encajar objetos rectangulares, estimar una caja interior compacta y comparar peso real con peso volumétrico.

## Verificación local

```text
npm run verify
```

El sitio se genera en `dist/` y se publica con GitHub Pages.

## Alcance

La V1 usa retículas ortogonales de objetos idénticos. No resuelve bin packing de formas mezcladas, encaje diagonal, resistencia del cartón ni tarifas de transporte.
