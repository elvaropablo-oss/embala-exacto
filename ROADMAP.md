# Hoja de ruta

## V1

- Comparar todas las orientaciones ortogonales de una pieza rectangular.
- Calcular una caja interior compacta para piezas idénticas.
- Calcular peso volumétrico con divisor y redondeo configurables.
- Explicar medidas interiores, exteriores y límites geométricos.

## Validación pendiente

- Probar los resultados de encaje con cajas y productos físicos de varias proporciones.
- Entrevistar a pequeños comercios para priorizar exportación, catálogos de cajas o mezclas de productos.
- Añadir un algoritmo para artículos diferentes solo si las pruebas muestran una necesidad recurrente.
